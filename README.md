

# 🧠 YouTube Spam Comment Detection using Machine Learning

A Flask-based web application that detects **YouTube spam comments** using a **Random Forest Machine Learning model**.  
This project includes data preprocessing, model training, user authentication, and real-time spam prediction.

---

## 📌 Project Overview

This system identifies spam comments using text processing and machine learning.  
It includes:

- User Registration & Login (with MySQL DB)
- Dataset viewing interface
- ML model training using Random Forest
- Spam / Non-Spam comment prediction
- Clean UI using Flask templates
- Published as an academic project (IJSRCSEIT Journal)

---

## 🧩 Features

✔️ User registration & login  
✔️ View YouTube comments dataset  
✔️ Text preprocessing using NLP  
✔️ ML model training (Random Forest Classifier)  
✔️ Predict comment as **Spam / Not Spam**  
✔️ Flask-based UI  
✔️ MySQL database connectivity
